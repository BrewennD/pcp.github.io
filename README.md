# Portfolio de compétences — Bréwenn Dassé

Bienvenue sur le dépôt de mon **portefeuille de compétences (PCP)** réalisé dans le cadre de mon **BTS SIO**, spécialité **SLAM** (*Solutions Logicielles et Applications Métiers*).

Le site est accessible en ligne :

**[https://brewennd.github.io/](https://brewennd.github.io/)**

## À propos du projet

Ce portfolio rassemble progressivement mon parcours, mes compétences et mes expériences professionnelles. Il me permet de présenter les notions étudiées en cours, les projets réalisés et les compétences acquises pendant ma formation.

Le site utilise principalement les composants et les utilitaires Bootstrap pour la mise en page responsive. Le CSS personnalisé se limite à la teinte violette des accents Bootstrap.

- **HTML5** pour structurer les pages ;

- **CSS3** pour une légère personnalisation violette de Bootstrap ;
- **Git et GitHub** pour versionner et publier le projet ;
- **GitHub Pages** pour l'hébergement du site.
